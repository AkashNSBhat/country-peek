# 🌍 CountryPeek

CountryPeek is a modern React web application that allows users to search and explore countries using real-time data from the RestCountries API.

---

## 🚀 Features

- 🔍 Search countries by name
- 🌐 Real-time data from REST API
- 📊 View country details:
  - Flag
  - Name & Official Name
  - Population
  - Region & Subregion
  - Capital
  - Languages
  - Currencies
  - Border Countries
- ⚡ Debounced search (optimized API calls)
- 🔄 Loading & error handling states
- 🔙 Back navigation
- 🎨 Clean and responsive UI

---

## 🛠️ Tech Stack

- React (Vite)
- React Router
- CSS (Custom styling)
- REST Countries API
